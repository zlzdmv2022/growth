## 三个核心判断

1. **「操作系统 + Agent」将取代「操作系统 + App」**——2026-06-01 黄仁勋台北宣布；不再装 App，用自然语言告诉 Agent 意图即可
2. **再好的模型裸跑复杂任务依然失败**——Anthropic 实验：同模型同提示词，裸跑 20 分钟废品，配 Harness 6 小时完全可用；Harness 是伴随 AI 长期存在的基础设施，更是模型的操作系统
3. **模型不再稀缺，稀缺的是能高效利用大模型的人**——人手一台法拉利，问题变成你能开多快；驾驭工程（构建 Harness）大概率是未来主要工作模式

## 你以为 vs 实际

| 你以为 | 实际 |
|---|---|
| AI 赋能每个人，效率差距会变小 | 只在一次性任务上成立；重复性工作的 Harness 收益每次累加，差距反而拉大 |
| Harness 是过渡期权宜之计 | 是长期基础设施，是「模型的操作系统」 |
| 产出不满意就改 Prompt | 停一秒：是前馈不够、反馈不够、还是状态丢了？改对应环节的 Harness |

## Harness 是什么

**马具比喻**：LLM 是的卢赤兔，再能跑也不知道你的意图、边界、标准——缰绳马鞍（Harness）让你告诉它、检查它、调整它。

**Agent 四组成**：LLM（大脑）+ Harness（身体）+ Tools + Runtime

**四个基本手段**（一次性提示词 → 可重复 AI 项目）：

```
项目仓库 Repository   工作内容落文件系统
前馈 Feedforward      结构/风格要求（提前说清楚）
反馈 Feedback          结果检查（亮点数/有数据/有责任人）
状态管理 State         文件留存上下文，跨次一致
```

## 两个 OPT 案例
